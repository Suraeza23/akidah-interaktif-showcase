# AKIDAH INTERAKTIF — Digital Innovation Showcase 2026

Laman utama responsif untuk dokumentasi dan pameran inovasi AKIDAH INTERAKTIF: SMART LEARNING SYSTEM.

## Fail
- `index.html` — struktur halaman utama
- `css/style.css` — reka bentuk responsif premium purple & gold
- `js/main.js` — menu mudah alih, pratonton borang pelawat dan pautan sistem
- `assets/images/` — simpan gambar dokumentasi di sini

## Sebelum diterbitkan
1. Gantikan ruang galeri dengan gambar sebenar.
2. Masukkan nama, gambar dan peranan penggerak inovasi.
3. Tambah pautan video YouTube.
4. Sambungkan borang visitor book dan feedback kepada Google Forms / Google Sheets atau Apps Script. Borang dalam versi ini hanya pratonton dan tidak menyimpan data.
5. Masukkan URL sistem sebenar pada pemboleh ubah `SYSTEM_URL` dalam `js/main.js`.
6. Gantikan pautan `mailto:ISI-EMEL-ANDA` dalam `index.html` dengan pautan Google Form maklum balas.

## Terbitkan melalui GitHub Pages
1. Cipta repositori awam baharu di GitHub.
2. Muat naik semua kandungan folder ini (pastikan `index.html` berada di root repositori).
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**, pilih `main` dan folder `/ (root)`, kemudian Save.
5. Tunggu proses penerbitan selesai dan buka URL GitHub Pages yang diberikan.
